# Hospital EMR — Electronic Medical Records & Hospital Management System

A modular hospital management application developed with **PHP, CodeIgniter 3, and MySQL**, designed to coordinate clinical, administrative, and financial workflows across hospital departments.

> **Portfolio showcase:** This repository contains project documentation only. The application source code is maintained in a separate private repository. Module status and deployment readiness depend on the current implementation.

## Project Overview

Hospital EMR supports coordinated patient journeys from reception and payment through consultation, laboratory requests, nursing care, pharmacy workflows, and inpatient admission. Role-based interfaces help departments focus on their responsibilities.

## Core Modules

| Module | Functionality |
| --- | --- |
| Reception & Patient Registration | Patient records, outpatient visits, consultation billing, and visit slips |
| Doctors | Consultation queue, patient visit workflows, clinical requests |
| Cashier & Billing | Payment processing, service charges, laboratory payment clearance, unified patient billing |
| Laboratory | Test requests, payment-gated processing, order statuses |
| Pharmacy | Medication dispensing workflows |
| Nursing | Nursing workflows and patient care support |
| Admissions & Inpatient Management | Ward admissions, bed availability, and allocation |
| Administration | Staff accounts, role-based access, services, and dashboards |

## Technical Highlights

- PHP and CodeIgniter 3 application architecture
- MySQL-backed clinical and operational workflows
- Role-based permissions and department-specific dashboards
- Integrated billing and payment-clearance rules
- Multi-department patient workflow coordination
- Modular controllers, models, and views
